# ActivityPub HTML Discovery

This is a repository for the **ActivityPub HTML Discovery Task Force** of the **Social Web Community Group (SWICG)** at the W3C, focused on discovery of ActivityPub objects from HTML.

The working draft of the report is at https://swicg.github.io/activitypub-html-discovery/

The group [meets](https://www.w3.org/events/meetings/ac2a4784-6c78-438f-a7cd-54c75d3511db/) on the second Wednesday of the month. The agenda is an GitHub issue with the [agenda](https://github.com/swicg/activitypub-html-discovery/issues?q=state%3Aopen%20label%3A%22agenda%22) label and the date of the meeting as the title (there's usually only one). Add a comment to the issue to add an item to the agenda.
